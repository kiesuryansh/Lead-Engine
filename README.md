# 🎯 Legal Lead Generation Engine

A **100% legal, 100% free** lead generation system using only public data sources and free APIs.

## ✅ Legal Data Sources Used

### 1. Government Business Registries (Public Data)
- **SEC EDGAR** - All US public companies (100% legal, public domain)
- **Companies House (UK)** - 4M+ UK companies (open data license)
- **OpenCorporates** - 200M+ companies worldwide (open database)
- **USPTO** - Trademark owners and businesses

### 2. Job Postings (Public Listings)
- **Adzuna API** - 5,000 calls/month free
- **USAJobs API** - Government contractors
- **GitHub Jobs** - Tech companies

### 3. Free Business APIs (Within Terms)
- **Hunter.io** - 25 free email searches/month
- **Abstract API** - Email validation (free tier)
- **Clearbit Logo API** - Free company enrichment

### 4. Open Datasets
- **Data.gov** - Government contracts and grants
- **Kaggle** - Public business datasets
- **OpenCorporates** - Open company database

## 🚀 Quick Start (< 5 minutes)

```bash
# Install dependencies
pip install -r requirements.txt

# Configure free APIs
python src/setup_wizard.py

# Extract your first 100 leads from SEC EDGAR
python src/examples/quick_demo.py
```
